Roles
HTML: es el esqueleto de la página, será útil para darle estructura y organizar todos los elementos de esta en cuanto a distribución y contenido, ejemplo: si quiero poner un párrafo y luego una lista de contenido.
CSS: se encarga del diseño de la página, sirve para definir el aspecto visual y la presentación de todos los elementos y contenido que habita en ella, ejemplo: el tamaño y ubicación de una imagen.
JavaScript: Se encarga de las funcionalidades, es el lenguaje que le da interactividad a la página, ejemplo: los botones o la intercomunicación entre pestañas.

Comprobación de herencia CSS con DevTools

2. Propiedad no heredada: margin-block-start, con un valor calculado de 16px. Esta propiedad representa el margen superior del párrafo y no se hereda automáticamente desde body.


Análisis de especificidad CSS en Rueda Libre

#menu a: especificidad (1, 0, 1). Define el color gris para los enlaces dentro del menú.
.activo: especificidad (0, 1, 0). Define el color verde y el grosor de fuente del enlace activo.

Causa del problema: El selector #menu a tiene mayor especificidad que .activo, por esta razón, el color gris prevalece sobre el verde.

Comportamiento responsive:

encabezado:
Cuando la página se estrecha poco a poco y la lista del menú ya no cabe en la pantalla, cada ítem del menú pasa a la siguiente linea ya que el contenedor utiliza flex-wrap:wrap para darle ese diseño responsive, el menú y el título de la página no se combinan uno encima del otro, y si se sigue estrechando, se inicia un scroll horizontal en el navegador.

pie de página:
Cuando la página se estrecha lo suficiente los ítem del footer no se anteponen uno encima del otro, mantienen un mínimo de distancia y si se sigue estrechado se inicia un scroll horizontal en el navegador.
